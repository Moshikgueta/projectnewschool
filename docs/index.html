מערכת פנימית אב־טיפוס

המקום אחד שבו כל מה שצריך לשיעור נמצא.

מחברות דיגיטליות, תלמידים, קבוצות וחומרי לימוד — לפי ההרשאה שלך. מורה רואה את התלמידים שלה; המשרד וההנהלה הפדגוגית רואים את בית הספר.

מחשב לוח בקרה התצוגה המלאה — תלמידים, מחברות, יומן שבועי, בונה מערך שיעור ופידבק. טלפון תצוגת מובייל השיעורים של היום, נוכחות, מחברות ופידבק — בדרך לכיתה.

כניסה לדמו

הנתונים מוטמעים בעמוד עצמו ואין מאחוריו שרת. הסיסמאות מוצגות בכוונה, כדי שאפשר יהיה להתרשם מכל התצוגות. אין כאן פרטי תלמידים אמיתיים.
